## Project rules
- Business facts (address, hours, WhatsApp, socials) live only in `src/config/siteConfig.ts`; menu in `src/data/menu.ts`, gallery in `src/data/gallery.ts` — components read from these so the owner edits one place.
- Never add unverified prices or contact details; `price: null` renders "Price on request".
- The hero pizza story is one GSAP ScrollTrigger pinned timeline in `PizzaStoryAnimation.tsx`; stage images must share identical framing (generated by editing the previous stage), and reduced-motion renders a static list.
- All WhatsApp links go through `src/utils/whatsapp.ts` (returns null → button disabled when no number).
